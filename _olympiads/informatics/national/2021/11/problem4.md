$N$ школьников из классов А и Б выстроены в ряд. $i$-й школьник в ряду сказал число $c_i$ – сколько школьников не с его класса стоят левее в ряду. Вам дан перемешанный массив $c$. Восстановите любое возможное изначальное расположение учеников.

#### Формат входного файла

В первой строке находится одно целое число $N(1 \leq N \leq 1.5 · 10^6)$.

Во второй строке находятся $N$ целых числа $x_1, x_2, ..., x_N (0 \leq x_i \leq N)$ — перемешанный массив $c$.

#### Формат выходного файла

Выведите изначальное расположение учеников в виде строки длины $N$ —состоящей из символов a и b. Гарантируется, что существует хотя бы одна такая строка.

Если есть несколько ответов, выведите любое из них.

#### Примеры

Ввод
```
4
1 0 2 0
```

Вывод
```
bbab
```
Ввод
```
5
0 0 2 1 3
```

Вывод
```
bbaba
```
