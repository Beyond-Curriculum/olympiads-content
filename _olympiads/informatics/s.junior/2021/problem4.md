Дан массив длины $N$ состоящий из неотрицательных целых чисел $a_1, a_2, ..., a_N$ и число $X$. Среди всех возможных пар чисел $L, R$ таких что $L \leq R$ и $a_L$ $\oplus{}$ $a_R = X$ найдите максимальное значение $min(a_L, a_{L+1}, ..., a_{R−1}, a_{R}) * (R−L+1)$. $\oplus{}$ - это побитовое исключающие ИЛИ.
#### Формат входного файла

Первая строка содержит 2 целых числа $N$ и $X $(1 \leq N \leq 10^5), (0 \leq X \leq 10^5)$. Вторая строка содержит $N$ целых чисел $a_i$ $(0 \leq a_i \leq 10^5)$. Гарантируется что во всех тестах существует хотя бы одна пара $L, R$ удовлетворяющая вышеописанным условиям.

#### Формат выходного файла

Выведите максимально возможное значение $min(a_L, a_{L+1}, ..., a_{R−1}, a_{R}) * (R−L+1)$ среди всех $L$, $R$ удовлетворяющих требованиям из условия.
