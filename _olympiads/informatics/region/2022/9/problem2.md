Даны три целых числа $x$, $y$, $z$. Вам нужно найти три целых положительных числа $a$, $b$, $c$, таких, что выполняются $x = ab$, $y = bc$, $z = ac$. Гарантируется, что ответ существует.

#### Формат входного файла

Единственная строка входных данных содержит три целых числа x, y и z(1 \leq x, y, z \leq 10^9).

#### Формат выходного файла

Выведите ответ на задачу

#### Примеры

Ввод
```
20 52 65
```

Вывод
```
5 4 13
```

Ввод
```
4082420 4086462 4084440
```

Вывод
```
2020 2021 2022
```
