В олимпиаде принимают участие $A$ девятиклассников, $B$ десятиклассников и $C$ одиннадцатиклассников.

Какое максимальное количество участников можно поставить в один ряд так, чтобы рядом стоящие не были с одной параллели?

#### Формат входного файла

В первой строке находится одно целое число $A(1 \leq A \leq 1000)$.

Во второй строке находится одно целое число $B(1 \leq B \leq 1000)$.

В третьей строке находится одно целое число $C(1 \leq C \leq 1000)$.


#### Формат выходного файла

Выведите ответ на задачу

#### Примеры

Ввод
```
3
3
2
```

Вывод
```
8
```

Ввод
```
5
2
1
```

Вывод
```
7
```
