### Задача B. Удаляем цифры

    <tr>

Даны два целых числа $n$ и $k$. Удалите $k$ цифр из числа $n$, чтобы новое число было максимально возможным. Гарантируется, что число $k$ меньше, чем количество цифр в $n$.

#### Формат входного файла

В первой строке входных данных находиться одно целое число $n (1 \leq n \leq 10^18)$.

Во второй строке входных данных находиться одно целое число $k (0 \leq k \leq 18)$.

#### Формат выходного файла

Выведите ответ на задачу

#### Примеры

Ввод
```
53342
2
```

Вывод
```
542
```

Ввод
```
102087607280291102
11 
```

Вывод
```
8891102
```
