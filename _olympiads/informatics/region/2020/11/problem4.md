Вам дано целое число $n$.

Найдите количество чисел от $1$ до $n$, которые имеют четное количество делителей.

#### Формат входного файла

В первой строке одно целое число $n$ $(1 <= n <= 10^9)$.


#### Формат выходного файла

Выведите ответ.

#### Примеры

Вход
```
10
```

Выход
```
7
```
