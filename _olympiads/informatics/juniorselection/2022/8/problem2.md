#### Задача B. Две строки
<table>
    <tr>
        <th>Ограничение по времени</th>
        <th>Ограничение по памяти</th>
    </tr>
    <tr>
        <td>1 секунда</td>
        <td>256 мегабайта</td>
    </tr>
</table>

Вам даны две строки состоящие из строчных букв латинского алфавита. Найдите длину НОП(Наидлиннейшая Общая Подстрока) этих строк. Подстрокой называется строка полученная путем удаления некоторых(возможно 0) элементов с начала и с конца строки. К примеру,подстроки строки "kazakh": "kazakh(1,6),"aza(2,4),"zakh(3,6) и.д.

#### Формат входного файла

Первая строка входных данных содержит два целых числа $n$ и $m$-длины строк. Вторая строка входных данных содержит две строки $s$ и $t$,состоящие только из строчных букв латинского алфавита.

#### Формат выходного файла

Выведите одно число - длину НОП

#### Примеры

Входные данные
```
4 5
frth
arthe
```

Выходные данные
```
3
```
Входные данные
```
6 5
afbghe
fbghk
```

Выходные данные
```
4
```
