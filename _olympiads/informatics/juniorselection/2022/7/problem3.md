У вас есть пустой вектор. Вам нужно выполнить $q$ запросов. Есть два типа запроса:

$1$ $x$ – добавить в конец вектора элемент $x$.

$2$ – реверснуть весь вектор. Например было $1, 2, 3$ станет $3, 2, 1$ после операции реверс.

Вас просят вывести каким будет вектор после всех этих операций.

#### Формат входного файла

Вам дается $q (1 \leq q \leq 300000)$ – количество запросов. Далее идет $q$ строк где в каждой строке описана операция.

#### Формат выходного файла

Вывести вектор после всех этих операций

#### Примеры

Входные данные
```
5
1 1
1 2
2
1 3
2
```

Выходные данные
```
3 1 2
```
Входные данные
```
10
1 1
1 2
1 3
1 4
1 5
2
2
1 6
2
1 7
```

Выходные данные
```
6 5 4 3 2 1 7
```
