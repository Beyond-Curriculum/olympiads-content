#### Задача A. Среднее число

Вам дается массив $A$ длины $N$ $(1 \leq N \leq 100)$. Нужно найти количество пар $(i, j)$ - где хотя бы один элемент на отрезке от $i$ до $j$ в массиве $A$ будет равен арифметическому среднему среди чисел на этом же отрезке.

Арифметическое среднее - сумме всех чисел множества, делённой на их количество

#### Формат входного файла

В первой строке входных данных вам дается целое число $N$. Во второй стоке вам дается массив целых чисел $A$.

#### Формат выходного файла

Нужно вывести ответ на задачу.
#### Примеры

Входные данные
```
4
1 1 2 3
```

Выходные данные
```
6
```
Входные данные
```
5
1 1 1 1 1
```

Выходные данные
```
15
```
