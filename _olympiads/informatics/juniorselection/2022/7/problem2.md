В магазине действует акции "купи 3, по цене двух самых дорогих книг". Конечно же покупатель может купить более 3 книг распределив их по группам из трех книг, где для каждой группы самую дешевую книгу берет бесплатно.

Вы как покупатель хотите заплатить как можно меньше.

#### Формат входного файла

Первая строка содержит $n$ $(1 \leq n \leq 10^5)$ - количество книг которые вы хотите купить.

Далее идут строки где в каждой строке записано число $с(1 \leq c \leq 10^5)$ - цена книги.

#### Формат выходного файла

Выведите минимальную сумму денег которую нужно заплатить.

#### Примеры

Входные данные
```
4
3
2
3
2
```

Выходные данные
```
8
```
Входные данные
```
6
6
4
5
5
5
5
```

Выходные данные
```
21
```
