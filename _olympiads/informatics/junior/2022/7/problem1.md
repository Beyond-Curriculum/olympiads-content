Вам дано два числа $L$, $R$. Ваша задача найти красивые числа от $L$ до $R$. Число $X$ называется красивой если она является палиндромом в двоичной системе счисления.

Числа $1, 3, 5, 7, 9$ являются красивыми, так как их представлении в двоичной системе счисление являются палиндромами $(1_2, 11_2, 101_2, 111_2, 1001_2)$.

#### Формат входного файла

В первой строке входных данных записаны два числа $L$ и $R$. $(1 \leq L \leq R \leq 10^9)$.

#### Формат выходного файла

Выведите ответ на задачу.

#### Примеры

Входные данные
```
1 10
```

Выходные данные
```
5
```
