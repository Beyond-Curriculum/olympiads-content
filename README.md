# BeyondOlympiads

Сайт с задачами и решениями олимпиад

## Как это работает?

### Начало работы

В первую очередь, откройте командную строку (cmd на Windows, Terminal на macOS) и перейдите в папку, где хотите разместить репозиторий. Для смены директории используется команда `cd`. Например:

```
cd C:\Users\morgunov\github
```

Затем клонируйте репозиторий с гитхаба:

```
git clone git@github.com:Beyond-Curriculum/olympiads-content.git
```

Готово:

### Фиксирование изменений

Если вы сделали какие-то изменения, вам нужно их коммитнуть. Для этого в командной строке перейдите в директорию с файлами:

```
cd C:\Users\morgunov\github\olympiads-content
```

Далее пропишите:
```
git add .
git commit -m "commit message"
```

Затем, если вы все делаете в первый раз, пропишите:
```
git branch -M main
git remote add origin git@github.com:Beyond-Curriculum/olympiads-content.git
git push -u origin main
```

Последняя команда `push` отправляет изменения в гитхаб. В последующем, вместо этих трех строк вы просто можете прописывать:

```
git push
```

### Добавление олимпиад/задач/решений

В каталоге `_olympiads` находятся файлы и папки, которые представляют из себя данные, используемые на данном сайте. 
- `_olympiads` Основная директория
    - `[subject]` Предмет
        - `[type]` Олимпиада
            - `[grade]` Класс
                - `[year]` Год
                    - `[file]` Сам файл
                    - `solutions` Папка с решениями
                        - `[file]` Файл с решениями
        - `s.[type]` Олимпиада без классов
            - `[year]` Год
                - `[file]` Сам файл
                - `solutions` Папка с решениями
                    - `[file]` Файл с решениями

То есть если вы хотите добавить олимпиаду, то вам нужно будет создать папку с названием олипиады, а точнее с его [slug](https://developer.mozilla.org/en-US/docs/Glossary/Slug)-ом. Далее, создать необходимые папки и файлы (класс, год, задачи/решения). 
Обратите внимание на то, что олимпиады без классов называются по типу `s.[type]`

### Добавление ссылок

Ссылки помещаются в JSON файл `urls.json`, который находится в папке года. Ссылки имеют следующую структуру:
```json
[
    {
        "url": "https://cdn.bc-pf.org/olympiads/chemistry/national/final/2019/chem9-1-tasks.pdf",
        "title": "PDF-файл"
    },
    {
        "url": "https://cdn.bc-pf.org/olympiads/chemistry/national/final/2019/chem9-1-tasks.pdf",
        "title": "PDF-файл 2"
    }
]
```

**Важно!**
Не забудьте добавить название олимпиады в словарь `TYPES`, который находится в `lib/constants.js`. Также, тут можно добавлять кастомные этапы и названия файлов.
