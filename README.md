# База данных Beyond Olympiads

## Обзор

В папке [_plans](_plans) содержатся планы подготовки в Markdown формате. Путь к файлам (названия папок и файлов) определяет URL плана. Например, файл [physics/plan12.md](_plans/physics/plan12.md) доступен по адресу [olympiads.bc-pf.org/plans/physics/plan12](https://olympiads.bc-pf.org/plans/physics/plan12).

В папке [_olympiads](_olympiads) содержатся задания/ссылки на задания олимпиад. На первом уровне содержатся папки с названиями предметов. На втором уровне названия олимпиад. Если название олимпиады начинается с "s.", олимпиада не имеет разделения на классы (s - single). На третьем уровне года. Если олимпиада имеет подразделения на классы, на четвертом уровне папки с классами. В противном случае, либо файлы с заданиями в Markdown/$\LaTeX$ формате ([пример](_olympiads/math/national/2018/9/problem1.md)) либо файл `urls.json` с ссылками на pdf файлы ([пример](_olympiads/math/national/2023/9/urls.json)). Визуализация структуры:

В каталоге `_olympiads` находятся файлы и папки, которые представляют из себя данные, используемые на данном сайте.

- `_olympiads` Основная директория
    - `[subject]` Предмет
        - `[type]` Олимпиада
            - `[grade]` Класс
                - `[year]` Год
                    - `[file]` Сам файл
                    - `solutions` Папка с решениями
                        - `[file]` Файл с решениями
        - `s.[type]` Олимпиада без классов
            - `[year]` Год
                - `[file]` Сам файл
                - `solutions` Папка с решениями
                    - `[file]` Файл с решениями

В файле `urls.json` прописываются ссылки на файлы и названия. Ссылки имеют следующую структуру:

```json
[
    {
        "url": "https://cdn.bc-pf.org/olympiads/chemistry/national/final/2019/chem9-1-tasks.pdf",
        "title": "PDF-файл"
    },
    {
        "url": "https://cdn.bc-pf.org/olympiads/chemistry/national/final/2019/chem9-1-tasks.pdf",
        "title": "PDF-файл 2"
    }
]
```

Любую ссылку можно разделить на два фрагмента:

- `https://cdn.bc-pf.org/olympiads/` - неизменно для всех файлов
- `math/national/final/2023/math-1-tasks.pdf` - путь к файлу в архиве (файл `math-1-tasks.pdf` в папке `2023`, которая в папке `final`, которая в папке `national`, которая в папке `math`)

Соответственно если вы хотите загрузить задания, вам нужно подготовить архив с pdf файлами (шаг №1) и создать `urls.json` (шаг №2), в котором прописать адреса к pdf файлам, с учетом названий папок в первом архиве.


### Пример действий

Допустим вы хотите загрузить задания республиканской олимпиады по математике 2024.

1. Даем файлам понятные названия на английском языке. Например `math-1-tasks.pdf` (задания 1 тура), `math-2-sol.pdf`(задания 2 тура). Если разные классы в разных файлах, можно заменить `math` на `math9` или `math11`.
2. Кладем файлы в папки: `math/national/final/2024` (создавать разные папки для разных классов необязательно)
3. Открываем текущий репозиторий, идем в [_olympiads/math/national/](_olympiads/math/national/), создаем папку `2024`, в которой создаем папки `9`, `10`, `11`, в которых создаем `urls.json`, в которых прописываем пути ко всем файлам. В данном случае, для файла `math9-1-tasks.pdf` путь будет `https://cdn.bc-pf.org/olympiads/math/national/final/2024/math9-1-tasks.pdf`.
4. Архив с файлами нужно отправить на `olympiads@bc-pf.org`. Обновленный репозиторий (с новыми файлами `urls.json`) запушить в новую ветку.

## Как запушить в новую ветку?

В первую очередь, подразумевается, что у вас есть локальная версия репозитория. Для создания этой локальной версии у вас должен быть установлен git (на macOS установлен по умолчанию, для Windows можно скачать [здесь](https://git-scm.com/downloads/win)). Дальше открываем командую строку/терминал и клонируем репозиторий:

```unix
git clone git@github.com:Beyond-Curriculum/olympiads-content.git
```

(это создаст папку `olympiads-content`). Готово.

### Фиксирование изменений

Если вы сделали какие-то изменения и хотите, чтобы они отразились в общем репозитории, вам нужно их коммитнуть. Процесс простой.

```bash
# Сначала создаем отдельную ветку, вместо oct5-updates можете выбрать любое другое название
git checkout -b oct5-updates
```

Как только вы закончили какие-то изменения, нужно сделать коммит:

```bash
git add .
git commit -m "Добавлена республиканская олимпиада по математике за 9 класс"
```

Если вы хотите добавить еще файлы, что-то изменить, что-то исправить, можете повторять процесс выше (`git add .`, `git commit -m "объяснение изменений"`) столько, сколько нужно.

Когда закончите, отправьте изменения в гитхаб:

```bash
git push origin oct5-updates
```

Затем откройте репозиторий, и вы увидите сообщение:

```
The branch oct5-updates has been updated recently. Do you want to create a pull request?
```

Нажмите на кнопку `Create pull request`, заполните форму и отправьте. Затем ждите, пока ваша ветка будет проверена и принята.
